# 🎀 Recreate FAQ Web App 🎀

あーしが作ったFAQアプリのソースコードへようこそ！

## 🚀 どんなアプリなの？

このアプリは、ユーザーが知りたいことをすぐに見つけられるFAQシステムだよ！
モダンな技術をこれでもかってくらい詰め込んだ、最強にエモいSPA（Single Page Application）なんだ✨

- **爆速FAQブラウジング**: カテゴリごとに整理されたFAQをサクッと確認！
- **スタイリッシュなお問い合わせ**: 悩みがあったらすぐ送れる、使いやすいフォームを搭載！
- **レスポンシブ対応**: スマホでもPCでも、どこから見ても可愛くて使いやすいよ💖

## 🛠️ 強強なテックスタック

あーしのこだわりが詰まった技術選定だよ！

- **Framework**: [Nuxt 4 (compatibility mode)](https://nuxt.com/) - 最新のNuxtで開発効率MAX！
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) - 爆速でオシャレなUIを実現！
- **Core Logic**: Nuxt Composables - ロジックを切り出して見やすく整理してるよ！
- **Testing**: [Vitest](https://vitest.dev/) + [@nuxt/test-utils](https://nuxt.com/docs/getting-started/testing) - 安心のユニットテスト完備！
- **Visual Testing**: [Storybook](https://storybook.js.org/) - コンポーネントをパーツごとに愛でることができるよ✨
- **Clean Code**: [ESLint](https://eslint.org/) + [Prettier](https://prettier.io/) - コードもあーしみたいに綺麗じゃないとね！

## 🏃‍♀️ クイックスタート

せんぱい、まずはここから始めてね！

### 1. 依存関係のインストール

```bash
npm install
```

### 2. 開発サーバーを起動！

```bash
npm run dev
```

`http://localhost:3000` であーしの力作が見れるよ！

### 3. テストを回す！

```bash
npm test
```

バグがないかチェック、チェック〜！

### 4. StorybookでUI確認！

```bash
npm run storybook
```

コンポーネントが動く様子をじっくり見てね💕

### 5. コードを綺麗にする

```bash
npm run format
```

## 📂 中身はどうなってるの？

- `app/` : ここがメインだよ！
  - `components/` : UIを構成するパーツたち。Storybookでも管理中！
  - `pages/` : 実際の画面。FAQとお問い合わせがあるよ！
  - `composables/` : アプリの頭脳！ビジネスロジックはここに集結！
- `server/` : APIサーバー。モックデータもここで管理してるよ！
- `tests/` : 大事な大事なテストコード！
